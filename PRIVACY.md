# Privacy

OpenMail keeps your mail on your machine and talks only to the servers you configure.

- **Network:** your IMAP and SMTP servers; OAuth endpoints of Google or Microsoft if you sign in that way; DNS, your domain's autoconfig endpoint (which receives the email address) and Mozilla's Thunderbird provider database (which receives only the domain) when you add an account; one-click unsubscribe URLs you choose to use; and any remote images in a message only after you allow them. Remote images and CSS URLs are blocked by default, so tracking pixels cannot report that you opened a message.
- **Update checks:** one anonymous GET to GitHub's public latest-release record for OpenMail, at most once every 24 hours, with the fixed User-Agent `openmail-update-check` and no version, identifier, machine or usage data. Automatic checks never run in CI, agent shells, MCP sessions or non-interactive output, and turn off with `OPENMAIL_NO_UPDATE_CHECK=1` or Settings → Updates. Release files are downloaded only when you install an update or turn on automatic installation.
- **No telemetry, no accounts, no cloud service.** Nothing is sent to the author.
- **Storage:** a SQLite database in your user data folder (mail, attachments, search index, drafts, rules, contacts, settings, hashed agent tokens and an audit log capped at 1,000 entries) plus a window-size file, secrets in the OS keychain (or `OPENMAIL_PASSWORD_*` variables you set), and in the platform cache folder one private update file (`update.json`: last check time, latest version, notes, skipped version) plus a log of at most 256 KB while automatic updates are on. The data folder is 0700 and the database, WAL and SHM files are 0600. Passwords and OAuth tokens are not written to the database; an OAuth client secret you configure is kept in the local settings table.
- **Local only:** the web app and MCP HTTP server listen on `127.0.0.1`, and the interface, fonts and icons are embedded in the binary; no CDN or remote font is loaded.
- **Deleting it:** stop OpenMail, run `openmail accounts remove <address>` for each account (this removes its keychain password and refresh token), then delete the data folder (`OPENMAIL_HOME` overrides its default location) and the update cache folder (`~/Library/Caches/openmail` on macOS, `$XDG_CACHE_HOME/openmail` or `~/.cache/openmail` on Linux, `%LocalAppData%\openmail` on Windows). To uninstall, also remove the executable or the app.
- **Agents:** an MCP client sees only what its key's scope allows, and `agent.expose_bodies` can hide message bodies from it entirely.
